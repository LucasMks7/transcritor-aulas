# Transcritor de aulas

Programa gratuito e de código aberto para Windows que transcreve o áudio de uma aula no próprio computador e gera um PDF com o texto. Se a pessoa pedir, o áudio e o PDF vão para o Google Drive dela.

- A transcrição acontece no computador: o áudio não é enviado a nenhum serviço de transcrição.
- O envio ao Google Drive é opcional e vem desligado. O programa só enxerga no Drive os arquivos e as pastas que ele mesmo criou.

É preciso ter permissão para gravar e para transcrever uma aula.
